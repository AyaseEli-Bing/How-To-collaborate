# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The DevBoard team takes security seriously. If you discover a security vulnerability within this repository, please do **NOT** open a public issue.

Instead, please send an email with the details to **[tusharrr0302@gmail.com](mailto:tusharrr0302@gmail.com)**.

### What to Include in Your Report:
- A clear description of the vulnerability.
- Steps to reproduce the issue or a proof-of-concept script.
- Potential impact and affected components.
- Any suggested fixes or mitigations.

### What to Expect:
- **Initial Response:** You will receive an acknowledgment within 48 hours.
- **Triage & Status Updates:** We will keep you updated as we investigate and validate the issue.
- **Resolution:** Once patched, we will coordinate a public release and credit you appropriately (if desired).
